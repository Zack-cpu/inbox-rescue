# Gmail review, beside your inbox

Inbox Rescue is an open-source side panel for reviewing messages misplaced in Spam and Promotions. This Preview is for early feedback.

**Anyone can try the fictional demo. Real Gmail access currently requires an invited account on the project's Google test-user list. Public Gmail sign-up and Google verification are not complete.**

## Install

1. Download `inbox-rescue-extension-v0.3.0-preview.zip` below. Do not use the automatic Source code ZIP.
2. Extract it and find the inner `inbox-rescue-extension` folder containing `manifest.json`.
3. Open `edge://extensions` or `chrome://extensions`, enable Developer mode, click Load unpacked, and select that folder.
4. Open Inbox Rescue from the toolbar. Try the demo, or connect your invited Gmail account. No Python, client ID, JSON file, or server setup is required.

[Detailed install/update guide](https://github.com/Zack-cpu/inbox-rescue/blob/main/docs/INSTALL.md)

## Included

- Preconfigured fixed-ID extension, MIT license, and installation guide
- Connect Gmail and automatic initial scan
- Separate Spam/Promotions queues, manual restore, and undo
- SHA-256 checksum file for the ZIP

Mail is processed in the browser with direct Google API requests. There is no app server, analytics pipeline, or third-party AI processing. Google asks for broad gmail.modify access; no send operation is implemented.

Scans are capped. New senders may have no correspondence match. Tokens expire, and undo actions disappear after clearing, rescanning, or reloading the panel. Disconnect does not reverse previous Gmail changes. Inspect Gmail before retrying a failed label update.
