# Changelog

## 0.3.0 Preview

This is an invited-testing preview, not general public Gmail availability.

- Browser side panel for desktop Chrome and Edge, distributed as a configured GitHub download.
- Project-supplied public OAuth client ID and a fixed unpacked test identity.
- Connect Gmail with an automatic first scan; optional fictional demo requires no Gmail access.
- Separate Spam and Promotions queues with explainable correspondence matches.
- Explicit restore to Primary and undo of the current panel's label delta.
- Message-count progress, expiry handling, disconnect, and clearer read/update failure messages.
- Installation guide, privacy summary, license, checksum, and Preview release workflow.

Known limits: real Gmail requires an invited Google test account; short-lived access requires reconnecting; undo state is not durable; scan windows and counts are capped; manual installation and updates are required. Google verification, store publication, and fixed-package testing across browsers are still in progress.
