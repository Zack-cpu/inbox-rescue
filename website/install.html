Get started

A small addition
to your everyday inbox.

Install the Preview in desktop Chrome or Microsoft Edge. No terminal, Python, or local server required.

Preview access: Anyone can try fictional mail. Connecting real Gmail currently requires an invited test account. Downloading does not grant that invitation.

1. Download the configured ZIP

Open the GitHub Preview release and choose inbox-rescue-extension-v0.3.0-preview.zip under Assets. Do not choose the automatically generated Source code ZIP.

Extract it to a permanent folder. Find the inner inbox-rescue-extension folder containing manifest.json. Keep that folder after installation; the browser loads the extension from it.

2. Load it in your browser

  1. For Edge, enter edge://extensions in the address bar. For Chrome, use chrome://extensions.
  2. Enable Developer mode.
  3. Click Load unpacked and choose the folder directly containing manifest.json.
  4. If you installed an older Inbox Rescue test build, disable that old copy to avoid opening the wrong version.

3. Open beside Gmail

Open Gmail as usual. Click the browser’s Extensions menu, pin Inbox Rescue, and click its toolbar icon. The review panel opens beside the page.

Select Try a demo instead to explore fictional messages. If invited, click Connect Gmail, select your Google account, and review the requested permission. The first scan starts automatically.

4. Review, then restore

Switch between Spam and Promotions. Inspect a message using View in Gmail, check that it is the connected account, and confirm Restore to Primary only after checking the sender. Undo remains available while the results are open.

Updating the Preview

Download a new configured release, extract it, and replace only the old extension’s application files with the new files. Click Reload on the browser’s extensions page, then close and reopen the panel. Alternatively, load the new folder and disable the old installation. Reconnect if prompted.

This GitHub Preview uses manual updates; it is not a store-installed extension.

Something went wrong?

  • Missing manifest: extract the ZIP first and choose the inner extension folder.
  • Google blocked access: verify that the selected address is invited. This is not solved by creating your own Cloud project.
  • Redirect mismatch: install the configured release ZIP. Contact the maintainer if the issue continues.
  • Expired connection: click Connect Gmail again.
  • Failed restore or undo: inspect Gmail before retrying; the update may already have succeeded.
